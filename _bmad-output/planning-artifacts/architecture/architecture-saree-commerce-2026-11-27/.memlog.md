- (decision) Mobile framework: Expo (React Native), not Flutter. Binds mobile + contracts. Prevents a second language and duplicated schema/types for one builder; Flutter had the stronger SDUI libraries but the chosen SDUI pattern (own block registry over typed JSON) needs none, and the saree viewer runs in a web view on either.
- (decision) The shop's own API is implemented as custom routes inside the commerce (Medusa) app, not a fourth deployable; clients reach standard commerce through Medusa's store API and Alar features through /store/shop/* routes, but only via one shared api-client package. Prevents clients coupling to two backends and keeps three server deployables.
- (decision) AI controls, consent, weavers, ratings, grievances, settings and audit live as custom modules in commerce with admin extensions; Payload owns screens, notices, policies and translations. Prevents two owners of one entity.
- (decision) One queue (BullMQ on Redis); worker never touches a database; reports back through an internal commerce API. Prevents a second writer of commerce state.
- (decision) Hold implemented as an expiring inventory reservation created at begin-checkout under the Redis locking provider; five named workflows are the only writers of stock.
- (decision) Razorpay webhook is the single source of payment truth; client callback only triggers a poll.
- (decision) Money stored and exchanged as integer paise; shelf prices are multiples of 100 paise; tax derived backwards with the residue in the tax line.
- (decision) Postgres on the same VM at first with continuous WAL archiving to off-VM object storage to meet the 15-minute Order-loss bound; all units containerised under one compose file for portability.
- (assumption) Owner uses two admin logins at launch (commerce admin and content admin), linked from each other; single sign-on deferred.
- (assumption) Search uses Postgres full-text at launch; a search engine is deferred until catalogue size or relevance demands it.
- (question) Does the free ARM allowance (2 CPU, 12 GB) carry commerce, content, worker, Postgres, Redis and Caddy with acceptable latency? To be measured in the spike.
