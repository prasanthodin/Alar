## Contradictions

- Apple interpreted-code clause: Capgo cites "3.3.1(B)", Bitrise cites "Section 3.3(b)"; Apple's own news item uses 3.3.1(B). Exact current wording not retrieved, and both summarisers sell OTA-update tooling.
- DivKit "cross-platform": the main README says iOS, Android, Web; a Flutter client exists in the repo, but its pub.dev package is 2 years stale while the web package shipped 4 days ago. Flutter support status is unresolved.
- RFW positioning: Very Good Ventures calls RFW "powerful"; the Flutter team's own README says moving a whole app to it "won't work" and compatibility is best-effort. These are compatible only if RFW is confined to component-composed surfaces.
- "Stac is production-ready" (vendor docs, tutorials) versus the facts that it is one young vendor (copyright 2025), was renamed from Mirai, and last published 2.5 months ago. No independent production retrospective for Stac was found.
- COD RTO rate: 26% (Shipway via Amazon Shipping), 28–35%, and 20–40% across vendor blogs. No neutral dataset.
- Reservation timing differs by platform: Medusa reserves at order placement, Vendure allocates at payment authorised/settled, Saleor allocates at checkout completion (with a separate reservation feature). None holds stock at add-to-cart by default — relevant for single-piece sarees.
